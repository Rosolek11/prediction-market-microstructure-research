# Security and disclosure policy

This public repository is a portfolio case study, not a deployable trading
system.

## Intentionally excluded

- source code;
- private keys and wallet information;
- API credentials;
- environment files;
- cloud project identifiers;
- server IP addresses and hostnames;
- SSH configuration;
- production dashboard URLs;
- live execution endpoints;
- raw market data containing operational metadata;
- exact deployment commands and service paths.

## Public-data policy

Only sanitized, non-operational documentation is published. Example records use
synthetic identifiers and approximate values.

## Reporting concerns

If a document appears to disclose operational information accidentally, open a
GitHub issue describing the filename and type of exposure. Do not attempt to
probe, scan, access, or test any system that might be associated with this case
study.
